# 🎮 SultanPro — 3D Game Platform

A premium, browser-based gaming dashboard built with pure HTML, CSS, and JavaScript.  
No install required — just open `SultanPro_3D_Game_Platform.html` in any modern browser and play.

## ✨ Features

- 🕹️ Multiple built-in mini-games
- 🌑 Sleek dark-mode UI with glassmorphism effects
- ⚡ Zero dependencies — runs entirely in the browser
- 📱 Responsive layout for desktop & mobile
- 🎨 Smooth animations and micro-interactions
- 🏆 Score tracking and leaderboard

## 🎮 How to Play

1. **Clone** the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/SultanPro-Game-Platform.git
   ```
2. **Open** `SultanPro_3D_Game_Platform.html` in your browser (Chrome / Edge / Firefox recommended).
3. **Play!** — No server, no build step needed.

---

## 🌐 Deploy on GitHub Pages (Free Hosting)

1. Go to your repository → **Settings** → **Pages**
2. Under **Source**, select `main` branch and `/ (root)` folder
3. Click **Save** — your game will be live in ~1 minute at:  
   `https://YOUR-USERNAME.github.io/SultanPro-Game-Platform/`
